# movie_discovery_app

I would like to start off by attributing all the data that is used in this project to tmdb themoviedb.org.

This project is entirely personal and will not be deployed for public use.

The data is pulled from their api.

## Goal

The goal of this project is to create a webapp that uses a realife webapp.

The webapp will have the the frontend made in html,css and JQuery, the backend will be made in node, express and axios.

The user will be able to search for movies using their names, they will also get recommendations for movies that are similar based on tags.

Of course the user will see the critic and audience score of the movie.

They will also get infromation about the movie like when it came out and etc.


## Functionalities

The user will be able to search for movies and see their ratings, movie posters and some extra information i can get from the api.

The user will also be able to discover movies. The user would fill in some filters and then see some movies displayed that fit the criteria that they have set. 

The discovery filters include things like region, release year, sort by popularity, vote_average, origin country, runtime and etc.
